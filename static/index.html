Welcome, to the CRM Backend

Overview of available endpoints:

  • POST /customers

    Create a new customer using the name, role, email and phone field.

  • GET /customers

    Get list of all current customers with their details.

  • GET /customers/?{id}

    Get details from specific customer using their id.

  • PUT /customers/{id}

    Send id and all details fields to url to update the specific customer via id.

  • DELETE /customers/{id}

    Send id for the specific customer to delete and remove from db.
